# Проверка имён моделей версии 3

Проверка от 2026-11-08 выполнена в dbt-контейнере без подключения к СУБД: чистый parse, изоляция контуров, SQLFluff и сравнение полных manifest. [Журнал](parse-lint.log).

[Сравнение с версией 2](manifest-check.json) подтверждает 12 переименований: три проекции `latest_anc_`, три агрегата `agg_anc_` и шесть фактов `fact_`. [Сравнение с исходной версией](manifest-check-from-v1.json) подтверждает все 36 переименований с учётом 24 конструкций ядра Anchor из версии 2.

Сохранены 168 моделей, 724 включённых теста, SQL, материализации, граф зависимостей и договоры тестов после нормализации согласованных имён, коротких SQL-алиасов и тега проекций. Зависимости сортируются после нормализации; пересчитываемый хеш служебного alias generic-теста исключается из сравнения.

Исполнение SQL и построение новых отношений на StarRocks не проверены. Эти результаты не заменяют приёмку данных. Переход существующего стенда описан в [инструкции](../../anchor-naming.md).
